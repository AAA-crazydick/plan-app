# 计划 Plan

简洁美观的手机优先任务计划 App（PWA）。无需安装服务器，部署到任意静态空间即可使用；手机浏览器打开后"添加到主屏幕"，就能像原生 App 一样使用，支持离线。

## ✨ 功能（v0.4）

- 🧭 **底部导航三模块**：「计划」「纪念日」「设置」独立分区
- ⚙️ **设置页**：提醒/提示音开关、关屏推送状态与重新同步、深色模式（跟随系统/浅色/深色）、数据导出导入（JSON备份）、清空数据；底部显示版本号
- 🎂 **倒数纪念日**：倒数日（未来）与纪念日（过去累计）卡片，大字显示天数；支持每年重复（生日/周年）、5种卡片颜色；点卡片编辑，右下角 + 新增
- ➕ **快速添加任务**：输入标题，可选日期（无/今天/明天/后天）、截止时间与优先级（低/中/高）
- ⏰ **分级提醒**（截止前按优先级弹出通知+横幅+提示音，需点右上角"🔔提醒"授权）：
  - 低优先级：提前 60 分钟
  - 中优先级：提前 60 分钟、15 分钟
  - 高优先级：提前 2小时、60分钟、30分钟、15分钟、5分钟、1分钟
  - 提醒在 App 打开时触发（iPhone 系统限制：网页App被完全关闭后无法本地定时弹通知；后续可升级推送服务）
  - iPhone 需先"添加到主屏幕"，从主屏幕打开 App 后点"🔔提醒"授权
- 📅 **三种视图**：今天（含过期提醒）/ 全部 / 已完成
- ✅ **完成任务**：点圆圈勾选，带动画
- ✏️ **编辑任务**：点击任务卡片，可改标题、备注、日期、优先级，或删除
- 📊 **今日进度环**：头部实时显示今日完成百分比
- 🌙 **深色模式**：自动跟随系统
- 📴 **离线可用**：Service Worker 缓存，断网也能用
- 💾 **本地存储**：数据保存在手机本地（localStorage），不联网不上传

## 📱 手机上使用（发布后）

1. 用手机浏览器访问 GitHub Pages 链接，例如 `https://你的用户名.github.io/plan-app/`
2. **iPhone**：Safari 打开 → 底部「分享」→「添加到主屏幕」
3. **Android**：Chrome 打开 → 右上角菜单 →「添加到主屏幕 / 安装应用」

## 🚀 发布到 GitHub Pages（纯网页操作，无需命令行）

1. 登录 [github.com](https://github.com) → 右上角 **+** → **New repository**
   - 名称填 `plan-app`，选 **Public**，点击 **Create repository**
2. 在新建的仓库页面点击 **"uploading an existing file"** 链接（或 **Add file → Upload files**）
3. 把本文件夹里的所有文件拖进上传区：`index.html`、`manifest.json`、`sw.js`、`README.md`、`icon-192.png`、`icon-512.png` → 点击 **Commit changes**
4. 进入 **Settings → Pages**，在 **Branch** 处选择 `main` / `(root)` → **Save**
5. 等待 1~2 分钟，访问 `https://你的用户名.github.io/plan-app/` 即可 🎉

## 🛠 技术

纯前端零依赖：单页 HTML + 原生 JS + CSS，localStorage 存储，Manifest + Service Worker 实现 PWA。
